# 设计规范入口

内容获得用户确认后，进入设计阶段时读取以下完整规范，不用此前的通用摘要代替原文：

1. [高级视觉设计V2.0](design-standards/AI_PPT_高级视觉设计知识库_MVP_V2.0.md)：五层结构、六类布局、3D光影、三类风格、字号/间距/配色及动效。
2. [执行与验收V1.2](design-standards/PPT视觉执行与验收_V1.2.md)：参数裁决、素材身份、两处确认、逐页设计依据及九项实际渲染验收。
3. [内容驱动设计方法V1.0公开版](design-standards/PPT内容驱动设计方法_V1.0_公开版.md)：内容关系到构图、素材准备、按需多方向探索、五维评审及实现边界。

用户明确的项目要求优先，其次为用户指定的当前有效规范，再采用本包默认规范。公开版不包含真实案例和私有路径。使用私有库的新版规范时，注明具体版本和差异，不能声称使用了未读取的规则。

只在内容批准后进行视觉基准选择与设计。HTML须覆盖完整计划并逐页检查，再等待用户批准当前版本；制作PPTX后独立渲染并核对。方向样页获选不能代替整套HTML确认。缺少渲染能力时记录未完成验收，未检查的页面不能标通过。

五维评审与九项验收共享已有渲染证据，不额外引入固定审批、评分系统或反复截图。文字溢出、遮挡、错误关系/数据、误导素材和核心不可读必须修复；主观偏好交由用户判断。

本包根LICENSE适用于新编写内容；改编的内容驱动方法另保留[原作者MIT许可](design-standards/licenses/huashu-design-MIT.txt)。不随包附带客户图片、第三方模板或私有规范登记文件。

文件保存与预览收尾按[项目存储与生命周期](lifecycle.md)：HTML预览PDF默认生成，成品预览PDF按需生成；两阶段实际验收不变，定稿回流收尾后常规逐页PNG保留一套PPTX渲染预览。
