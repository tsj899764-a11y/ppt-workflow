# AI PPT 高级视觉设计知识库 MVP V2.0

> PPT 视觉美学与页面设计规范  
> **定位：** 专业商业演示设计 + 现代 UI 设计 + 高级视觉表现  
> **目标：** 让 AI 生成的 PPT 达到专业设计师制作的商业演示水平，而不是传统模板式 PPT。

---

## 一、设计定位与基本原则

现有 PPT 知识库负责提供**内容知识**，包括页面应该讲什么、需要表达哪些业务信息及业务逻辑。本规范仅负责 **PPT 的视觉表现**：

- 页面结构与构图
- 色彩与字体设计
- 视觉层次与空间关系
- 图形、卡片与信息可视化
- 3D 模型与高级光影
- 页面动效与设计细节

**核心原则：历史 PPT 学习内容，新视觉规范决定设计。** 不继承历史 PPT 中过时的排版、配色和视觉风格。

### 整体设计方向

默认采用 **70% 现代极简商务风 + 30% 未来科技风**。这个比例表示设计倾向，而非严格的色彩占比。

**设计关键词：** 高级、简洁、通透、精致、立体、专业、科技、现代。

最终页面应呈现：

1. 具有专业设计师的构图能力。
2. 具有现代 UI 设计的精致质感。
3. 具有合理的视觉层次和空间纵深。
4. 具有恰到好处的 3D 与光影效果。
5. 具有丰富但统一的页面表现形式。

**设计强调克制，不以元素数量或特效复杂度衡量美观度。**

## 二、页面五层视觉结构

| 层级 | 设计内容 | 视觉效果 |
|---|---|---|
| L1 背景层 | 渐变、纹理、几何背景 | 营造高级视觉氛围 |
| L2 标题层 | 主标题、副标题、章节标识 | 建立信息层级 |
| L3 内容层 | 文字、卡片、流程、架构 | 承载核心信息 |
| L4 视觉层 | 3D 模型、图片、数据图形 | 建立视觉中心 |
| L5 装饰层 | 光影、连接线、微图形 | 提升设计精致度 |

> 五层是分析与设计维度，不代表每页必须使用全部五层。

### 2.1 背景层

背景不能只是机械地填充颜色，可根据页面类型使用：

- 柔和线性渐变
- 径向渐变与局部光晕
- 低透明度几何装饰
- 细微科技网格
- 柔和曲线与流体背景
- 适度模糊的场景图片

**要求：** 背景有质感，但不能抢占内容的视觉权重。

### 2.2 标题层

主标题大而醒目，副标题简洁。可以增加英文装饰性章节标识、页面编号、品牌色强调文字和精细分割线，但避免复杂标题装饰。

### 2.3 内容层

根据业务信息选择合适的表达方式：卡片、流程、分层结构、关系网络、信息图表或产品界面，而不是简单将所有文字塞进矩形。要求对齐规范、间距统一、分组清晰。

### 2.4 视觉层

这是提升 PPT 美观度的关键。重点页面应拥有与内容相关的明确视觉主体，例如：

- 高质量 3D 场景
- 数字化园区模型
- 产品界面
- 精致架构图
- 信息可视化图形
- 高级商务插画
- 关键数据组合

### 2.5 装饰层

适度使用精细线条、光效、几何图形、微型标识和连接关系，增强整体完成度，不为了填满空白而增加装饰。

## 三、六大核心布局体系

| 布局 | 设计方式 | 适用页面 |
|---|---|---|
| 左文右图 | 一侧信息、一侧核心视觉 | 方案概述、产品介绍 |
| 中心辐射 | 中央主体、外围功能模块 | 总体方案、能力体系 |
| 分层架构 | 横向分层、纵向关联 | 技术架构、业务架构 |
| 横向流程 | 节点与路径形成逻辑顺序 | 业务流程、实施计划 |
| 网格组合 | 不同尺寸卡片灵活组合 | 功能介绍、应用场景 |
| 大视觉主导 | 场景或核心图形占据主要区域 | 封面、重点展示 |

### 布局高级化要求

1. **非对称构图：** 不机械居中；合理运用左右不等比例、错位模块及大小对比。
2. **视觉重心：** 页面可以包含多个信息模块，但应有一个明确的主要视觉焦点。
3. **空间留白：** 元素之间保留呼吸感，不为了填满页面添加无意义内容。
4. **视觉节奏：** 整套 PPT 有疏有密、有大有小；避免连续多页重复三卡片、四卡片。
5. **组合布局：** 允许「左侧核心信息 + 右侧 3D 场景 + 底部数据指标」等融合布局，但必须保持视觉平衡与可读性。

## 四、六大高级视觉效果

### 4.1 空间层次设计

通过前景、中景和背景建立视觉纵深：

- **前景：** 核心数据、重点信息、悬浮标签。
- **中景：** 产品模型、架构模块、主要视觉主体。
- **背景：** 渐变、环境场景、柔和光效。

通过大小变化、遮挡关系、阴影和透视形成空间感，让 PPT 不再只是平面的文字与矩形。

### 4.2 轻量化 3D 设计

| 页面 | 推荐 3D 元素 |
|---|---|
| 智慧园区 | 等距视角数字园区模型 |
| AI 平台 | 立体智能核心与能力网络 |
| 数据平台 | 立体数据结构与流向 |
| 技术架构 | 2.5D 分层平台 |
| 产品介绍 | 立体设备与产品界面 |
| 智慧能源 | 能源设备与网络模型 |

**3D 设计原则：**

- 一个页面通常只有一个主要 3D 主体。
- 3D 风格、光源与透视角度统一。
- 优先使用精致、克制的 3D 设计。
- 不允许 3D 效果破坏信息可读性。
- 不要求所有页面采用 3D。

**3D 是视觉增强手段，不是每页的必备元素。**

### 4.3 高级光影设计

- **柔和投影：** 用于悬浮卡片、功能模块和产品界面。
- **局部光晕：** 用于突出核心平台、关键数据和重点节点。
- **渐变高光：** 用于强调标题、重点图形和品牌视觉。
- **玻璃质感：** 用于部分浮层和科技信息面板。

要求光影自然、透明度适中、边缘柔和，避免大面积高强度发光和厚重阴影。

### 4.4 精致 UI 组件

引入现代产品 UI 的视觉语言：

- 精细圆角卡片
- 统一的图标系统
- 低透明度边框
- 柔和渐变填充
- 悬浮信息面板
- 数字标签
- 微型状态标识
- 精致分割线

**注意：** 组件风格应统一，但不能把所有 PPT 页面做成软件后台界面。商业演示仍应保留大标题、大视觉和空间留白。

### 4.5 信息图形化设计

| 信息关系 | 推荐视觉表达 |
|---|---|
| 并列 | 卡片、图标组合 |
| 递进 | 阶梯、路径、箭头 |
| 层级 | 分层架构、树形结构 |
| 关联 | 节点网络、连接线 |
| 对比 | 双栏对比、视觉分区 |
| 循环 | 环形流程、闭环模型 |
| 数据 | 图表、大数字、趋势线 |

不默认使用「图标 + 标题 + 描述」的重复卡片形式。

### 4.6 精细装饰设计

可以适度使用微型几何元素、浅色科技网格、低透明度数字纹理、细线连接、辅助圆环、柔和渐变色块与章节英文标识。

**宁可减少装饰，也不要降低页面质感。**

## 五、三套高级视觉风格

### 5.1 风格 A：现代极简商务风

**关键词：** 简约、专业、克制、高级。

- 白色或浅灰背景
- 大面积留白
- 深色标题、品牌色强调
- 精致图表与清晰布局

**适用：** 正式汇报、企业介绍、项目背景、复杂架构。

### 5.2 风格 B：明亮科技商务风

**关键词：** 通透、立体、科技、精致。

- 浅蓝渐变背景
- 柔和光晕
- 悬浮卡片
- 轻量化 3D
- 清晰信息层次

**适用：** 智慧园区、数字化建设方案、AI 应用、产品介绍。  
**默认建议：** 软件类解决方案优先使用该风格。

### 5.3 风格 C：深色未来科技风

**关键词：** 沉浸、未来、科技、视觉冲击。

- 深蓝背景
- 蓝紫渐变
- 局部发光
- 空间模型
- 科技线条

**适用：** 封面、核心能力展示、重点方案总览；不建议大量正文页面连续使用。

### 5.4 风格统一要求

一套 PPT 可有不同复杂度的页面，但应统一字体体系、基础配色、图标语言、圆角风格、光影方向与图形质感。

## 六、重点页面视觉设计规范

| 页面类型 | 核心设计要求 | 推荐视觉 |
|---|---|---|
| 封面页 | 视觉冲击、品牌感、简洁 | 大型 3D 场景、抽象科技视觉 |
| 背景页 | 信息清晰、场景感 | 大图搭配精简文字 |
| 痛点页 | 对比明确、重点突出 | 分组信息图、对比结构 |
| 建设目标页 | 重点突出、层级明确 | 中心辐射、目标模型 |
| 总体架构页 | 逻辑清楚、结构专业 | 分层架构、2.5D 结构 |
| 功能介绍页 | 精致、直观、易理解 | 产品界面、功能卡片 |
| 业务流程页 | 路径清晰、顺序明确 | 流程图、路径连接 |
| 数据价值页 | 数据醒目、图表精致 | 大数字、简洁数据图表 |
| 总结页 | 观点鲜明、视觉完整 | 大标题、核心视觉 |

### 架构图专项设计要求

架构页不能等同于多个矩形堆叠，也不能一味追求复杂 3D 效果。

**推荐表达：二维信息结构 + 局部立体视觉 + 清晰业务连接。**

1. 不同架构层级通过色彩、位置和尺寸进行区分。
2. 核心平台具有更高的视觉权重。
3. 模块排列整齐，但允许适度的创新构图。
4. 使用连接线或箭头体现真实依赖关系。
5. 以光影表现层次，不必使每一层都复杂化。
6. 复杂架构优先考虑信息完整性与可读性。

**架构页首先是一张专业架构图，其次才是一张漂亮的 PPT。**

## 七、精细化设计标准

以 **1920 × 1080 的 16:9 设计画布**为参考：

| 设计项目 | 建议标准 |
|---|---|
| 页面安全边距 | 80～120 px |
| 页面主标题 | 40～52 px |
| 副标题 | 20～26 px |
| 模块标题 | 24～30 px |
| 正文文字 | 20～26 px |
| 辅助说明 | 16～20 px |
| 重点数据 | 48～80 px |
| 卡片圆角 | 12～20 px |
| 卡片内边距 | 24～36 px |
| 模块间距 | 24～40 px |
| 主色数量 | 1 种 |
| 辅助色数量 | 1～2 种 |

以上是设计参考值，实际生成时需按 PPT 页面尺寸等比例换算，并根据展示设备和可读性调整。

### 7.1 颜色规范

| 用途 | 推荐色值 |
|---|---|
| 主色：科技蓝 | `#1769FF` |
| 深色：商务深蓝 | `#142A50` |
| 辅助色：青色 | `#36D6E7` |
| 浅背景 | `#F3F8FF` |
| 正文色 | `#26344A` |

- 一页保持一个主色调。
- 强调色用于核心数据、图标和重点节点。
- 大面积背景避免高饱和度。
- 渐变自然柔和。
- 文字与背景保持足够对比度。

### 7.2 字体规范

优先使用现代、简洁的无衬线字体：标题加粗、正文常规字重、数字适当放大；字距与行距自然，避免在一套 PPT 中混用过多字体和艺术字。

## 八、页面视觉动效

动画只用于增强讲解，不是每页必需元素。

| 对象 | 推荐效果 |
|---|---|
| 页面标题 | 轻微上移、淡入 |
| 卡片 | 顺序渐入 |
| 流程 | 节点逐个显示、连线延伸 |
| 架构 | 分层展开 |
| 核心数据 | 数字递增 |
| 页面切换 | Morph 平滑过渡 |

常规动画建议 **0.3～0.6 秒**。避免无意义的旋转、弹跳与复杂飞入。无法实现的动画效果不得标注为已实现。

## 九、视觉设计质量标准

| 维度 | 设计标准 |
|---|---|
| 构图 | 视觉重心明确，布局合理 |
| 层次 | 标题、主体、辅助信息主次分明 |
| 美感 | 配色协调、光影自然、细节精致 |
| 空间 | 留白合理，具有视觉呼吸感 |
| 统一 | 整套 PPT 设计语言一致 |
| 创新 | 根据内容变化构图，避免模板化 |

### 必须避免的设计问题

- **低级排版：** 大量文字直接堆叠，缺少视觉设计。
- **重复布局：** 所有页面都使用相同卡片结构。
- **视觉拥挤：** 一页承载过多内容，没有留白。
- **过度科技化：** 发光、渐变和复杂 3D 无节制堆叠。
- **廉价装饰：** 无意义的线条、图标、背景图形。
- **设计失衡：** 图形过大、文字过小、页面重心偏移。
- **风格混乱：** 3D、扁平插画、卡通图标随意混用。
- **海报化：** 页面炫酷，但缺少演示所需的信息组织与阅读顺序。

## 十、最终设计准则

> 以专业商业演示设计为基础，融合现代 UI 设计、精致信息图形与适度 3D 科技视觉。
>
> 每一页必须拥有合理的构图、明确的视觉焦点、清晰的信息层次和统一的设计语言。
>
> 合理使用非对称布局、空间留白、悬浮信息组件、柔和渐变、立体模型与高级光影，提升视觉质感。
>
> 根据内容特点灵活选择布局，不机械套用三卡片、四卡片等传统模板。
>
> 对架构图、流程图、数据图等信息型页面，优先保证逻辑准确与视觉清晰；对封面、方案总览、产品展示等重点页面，适度增强视觉创意和空间表现。
>
> 所有视觉效果服务于内容表达，不能为了追求美观而影响信息可读性。
>
> 设计风格应达到专业商业演示水准，避免传统模板式排版，也避免过度炫酷的科技海报风格。

**最终目标：让每一页都像经过专业设计师精心设计，而不是由 AI 简单拼接文字、图片和卡片。**

---

**使用原则（最重要）：现有 PPT 知识库决定「讲什么」，本规范决定「怎么设计得好看」。历史 PPT 只作为内容参考，不继承其不佳的视觉排版。**
