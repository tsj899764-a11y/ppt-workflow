# PPT Workflow 0.2.1

可分发Skill版本0.2.1。通用方法、只读检索工具与虚构示例公开；使用者自行连接私有资料库。本包不含真实公司PPT、客户案例、私有索引或预览，也不自动上传或发布内容。

## 安装与开始

将`skills/ppt-workflow`整个文件夹复制到支持Agent Skills的宿主技能目录。例如Codex项目可放`.agents/skills/ppt-workflow`，具体宿主以其当前官方文档为准。不要把自己的资料库复制到Skill目录。此版本通过GitHub分发，尚未打包成插件。

调用示例：

> 使用 $ppt-workflow，为我提供的项目资料编排一份售前PPT，先提交逐页内容供我确认。

> 使用 $ppt-workflow，检索我指定的私有知识库，找相关内容参考。资料库路径由我单独提供。

不接私有库也能使用通用骨架与流程。命令行试用：从本包根目录运行

```bash
python3 skills/ppt-workflow/scripts/kb_search.py "运营" --include-text
```

接私有库使用`--kb`或`PPT_KB_ROOT`，详见Skill内references/library.md。Python最低3.10，检索无额外依赖。HTML制作、浏览器检查、可编辑PPTX生成与渲染依赖宿主现有工具，本包不提供这些引擎。

## 能力与发布范围

流程为内容编排与确认、HTML设计与确认、PPTX制作与独立验收、最终采用后的私有回流。检索支持主题/摘要/标签匹配、A/B候选过滤、规范页去重及命中页正文读取；不支持全文向量检索、自动解析PPT、自动发布入库、自动原件归档或清理。

在私有环境使用时，检索结果仍可能包含敏感内容。脚本不联网；宿主模型服务如何处理输入需使用者确认。本包不提供“零泄漏”保证。

发行包由tools/build_release.py中的明确文件白名单生成，拒绝白名单路径中的符号链接，检查常见个人路径和凭据样式。扫描只是辅助，不能判断全部商业秘密或再分发权限。tests/test_tools.py使用临时虚构数据测试检索、过滤、去重和安全边界。

```bash
python3 tests/test_tools.py
python3 tools/build_release.py --output ../ppt-workflow-v0.2.1.zip
```

本包新编写的通用方法、脚本、用户授权公开的设计规范与虚构示例采用MIT许可。内容驱动设计方法包含MIT许可的改编内容，原作者署名及完整许可随包保留。许可不覆盖使用者的私有库、第三方素材或宿主工具。私有资料及第三方素材不在本公开发行范围内。

## 完整设计规范

V0.2.1接入视觉设计V2.0、执行验收V1.2及内容驱动设计方法V1.0公开版。Skill在内容批准后的设计阶段读取完整规范，不仅依赖摘要。公开版移除真实案例、私有引用与内部授权记录，保留第三方署名及MIT许可。入口见skills/ppt-workflow/references/design.md。

## 完整骨架库

包含S001–S010共10套骨架，附逐步写作任务、页数预算与机器CSV。移除了私有资料ID和来源案例引用。默认页数是可调整建议，不是实际项目承诺。

## 项目存储与预览

同一实质版本集中保存内容、HTML和交付；确认记录合入清单，HTML/PPTX验收区分记录。小修订文件级另存，实质变化另建版本目录，定稿不重复复制归档。默认生成HTML预览PDF，成品预览PDF按需生成；定稿回流收尾后常规逐页PNG保留一套PPTX成品预览。必要历史证据及依赖素材继续保护；清理复用宿主机制，未登记文件先列具体清单确认。详见Skill的references/lifecycle.md。
