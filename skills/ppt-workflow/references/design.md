# 内容驱动设计与验收

此文件为公开包的原创通用执行摘要，不复制私有库规范原文、第三方方法或模板。用户指定的有效规范和品牌要求优先。

内容获批后，确定统一的颜色、字体、字号层级、画布、安全边距、图标与组件。默认可使用明亮商务科技方向：主色#1769FF、标题#142A50、辅助#36D6E7、浅底#F3F8FF、正文#26344A；这些为可替换起点，不用于评价所有项目。

先判断关系再选择构图：并列用卡片、层级用分层、顺序用流程、关联用节点、对比用两栏、数值用图表。每页突出一个核心论点，内容超出容量时重组或拆页，不靠不断缩字。相邻页面按信息需要变化布局；留白、对齐、阅读顺序优先于装饰。3D与渐变只在帮助理解时加入，不把技术图当海报。

保存每页设计意图、实际构图、内容依据和素材来源。真实项目图片须确认身份；AI场景如易与事实混淆，在展示语境中标概念示意。授权状态未知就如实记录，不把“已脱敏”当作可再分发的证明。

HTML覆盖所有计划页及完整内容，实际打开并逐页查看后才提交确认。记录自检与用户确认分别对应的版本；PPTX由批准HTML制作，文字、图形、图表尽量保留编辑性，图片作为独立素材。

PPTX独立渲染，与批准HTML对照。必要检查：焦点与构图、层级、留白与对齐、组件质感、逻辑与可读性、风格一致、合理页面变化、素材身份、渲染完整。溢出、遮挡、关系或数据错误、误导性素材、核心文字不可读须修复；主观偏好交给用户。未查看实际渲染不写通过，未播放验证不写动效已验证。一次有效检查后只复测修复范围，不为主观审美无限迭代。
