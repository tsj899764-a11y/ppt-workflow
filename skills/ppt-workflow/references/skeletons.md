# 通用叙事骨架

这些主线为本公开包重新编写，未附带真实项目案例。按受众需要组合，缺少预算、案例或成效证据时写待补，不编造。

| 用途 | 主要决策 | 建议主线 |
| --- | --- | --- |
| 行业售前 | 是否值得进一步交流 | 行业变化、关键问题、方案目标、整体方法、架构、重点场景、交付条件、价值评价、下一步 |
| 客户定制售前 | 是否采纳针对当前问题的方案 | 客户现状、问题证据、目标与范围、方案选择、架构与场景、系统衔接、实施路径、投入假设、决策事项 |
| 顶层规划咨询 | 如何分阶段配置资源 | 战略与范围、角色需求、业务能力、建设原则、场景优先级、总体及专项架构、项目组合、分期与资源、治理及决策 |
| 平台产品介绍 | 产品是否适合使用 | 目标用户、使用问题、产品定位、能力总览、典型任务、真实演示、集成与部署、权限安全、支持边界、下一步 |
| 项目申报立项 | 是否具备建设必要性与可行性 | 背景依据、对象与目标、建设范围、资源条件、架构与功能、数据与责任、实施计划、投资依据、预期效益与评价 |
| 峰会专题演讲 | 观点是否可信且有启发 | 问题与观察、核心观点、分析方法、实践过程、证据与限制、启示、可行动建议 |
| 公司介绍 | 是否具备合作能力 | 公司定位、业务能力、团队与资质、经授权案例、交付方式、合作入口 |

内容稿逐页字段：页码、标题、核心结论、正文要点、证据定位、事实状态、内容参考ID、待补事项。仅在论点需要时增加案例或经济测算；不可拿虚构示例充当客户成绩。
